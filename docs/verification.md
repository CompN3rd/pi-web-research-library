## Verification limits

The repeatable `npm run smoke:browser` command uses compiled package entries behind a synthetic public authority/transport/session-events adapter, **not a real session daemon or provider**. The separately authorized real-host check above is distinct from that command. The extracted-tarball probe exercises storage, bibliography/CSL and the actual unpdf worker outside repository devDependencies. Server network requests are forbidden in both probes; discovery is local-only.

Real local host discovery and cold-start activation are established by the isolated check above. Managed service installation/restart, live provider execution/result delivery, the user's existing provider/extension profile, public Crossref/OpenAlex behavior and remote federation remain unverified. Real data migration and deployment beyond the local environment remain untested. Verification alone authorizes no version bump, npm publishing or live deployment. A deployment requires separate authorization; session-daemon restarts interrupt active sessions and terminals.

OCR, live Word/Google Docs fields, cloud collaboration/sync, automatic alerts and vendor integrations are outside scope. Large real-world bibliography/PDF corpora, cross-process writers, hostile same-account filesystem mutation and power-loss durability are not proven by synthetic tests. The configured Linux/Windows and Node 22.19/24 CI matrix is not evidence that remote CI ran. Agent-assisted review and automated license checks are not security or legal certification.
