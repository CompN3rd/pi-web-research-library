Create passage-linked comments from selected PDF text without leaving Reader. Use native text selection or the keyboard/touch start/end text-run picker, then save, reopen and edit through the existing evidence editor. Comments preserve the selected quote, source identity and a single-page bounding rectangle. This adds one-page comments, not highlight-only saving or multi-page text anchors; source PDFs and existing annotations are unchanged.
