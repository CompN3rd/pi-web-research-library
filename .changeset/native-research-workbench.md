Add a native local reference, evidence, research and manuscript workbench without reference-manager accounts or vendor MCP integrations.

- Manage references, citation aliases, collections/tags, reading/screening state, duplicate review, trash and portable BibTeX/RIS/CSL-JSON imports/exports.
- Attach verified PDFs, index text locally in a bounded worker, collect source-bound evidence and retrieve indexed passages through native Pi tools.
- Explicitly admit frozen-corpus research tasks, validate durable structured results, and keep execution, human acceptance and manuscript application separate.
- Edit/audit manuscripts with CSL citations, portable exports and separately confirmed revision/hash/preview-bound file writes with recovery backups.
- Offer optional consented public scholarly metadata discovery, manual saved queries and honestly labeled local connection views.

Library and Discover are the only product panels, backed by one workspace catalog. The earlier pilot/synthetic application has been removed; archived workspace records are neither read nor rewritten, and no automatic data migration is performed. OCR, live Word/Google Docs citation fields and cloud collaboration/synchronization are not included. Public sessions/session-events v1 are required; plugin server changes need an operator-controlled session-daemon restart when safe, which interrupts active sessions and terminals. No host restart, deployment or publishing is performed automatically.
